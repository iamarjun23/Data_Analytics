Terms on this page
WISMO
"Where Is My Order" — the ticket reason customers raise when they're waiting and worried.
Holdout
10% of orders deliberately left un-messaged, so there's a fair baseline to measure the outreach against.
DND / consent
Customers who've opted out of a channel, or asked not to be contacted — the system is not allowed to message them even if they're flagged.
Quiet hours
No calls or messages are sent outside 09:00–21:00 IST, regardless of urgency.
Intent-to-treat
A statistics rule: orders we flagged but couldn't actually reach still count in the "treated" group, so the measured benefit isn't inflated.

Terms on this page
Schema contract
A written definition of what fields a source should send and their types. If the vendor renames or removes one, the run fails loudly instead of loading bad data.
UNMAPPED
A value (like a new courier status code) nobody has translated yet. It's kept and flagged, never silently dropped or guessed at.
Look-back
Every run re-reads the last 3 days, not just "new since last time" — so if a ticket gets edited two days after it was created, the pipeline still catches the edit.
Reconciliation
Comparing the pipeline's own daily row counts against the vendor's source counts, to prove nothing silently went missing.
Provisional (*)
A day's numbers that can still change because some outcomes (like a delivery status) arrive a few days late.

Terms on this page
Match tier (A–D)
How confident the system is that two records belong to the same person. A = exact match (same phone), D = weak signal — held for a human to confirm, never auto-merged.
Cluster
All the accounts, phones and bookings the system believes belong to one real customer.
no_consent / dnd
The customer hasn't opted in to this channel, or has asked not to be contacted — excluded from outreach regardless of how overdue they are.
Holdout
10% of eligible customers deliberately not called, to measure what the outreach actually changed.
95% interval
The range the true effect probably falls in. When it crosses zero, it means "probably helps, but not proven yet with this much data."

Terms on this page
Rubric
The written checklist the auditor scores every conversation against — the same questions a QA reviewer would ask.
Open / half-open / closed
Breaker states: open = something broke, the flow is paused for review; half-open = a small test slice is running under watch; closed = healthy, running normally again.
κ (kappa)
A statistic for "do two reviewers agree, more than they would by chance." 1.0 is perfect agreement; above 0.8 is considered strong.
Write-back / read-back
The system writes a result into the ticket system, then immediately reads it back to prove the write actually took — catches silent failures.
